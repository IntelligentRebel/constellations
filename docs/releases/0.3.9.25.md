## What's new in 0.3.9.25: a game by turn files with no files to send

**A shared folder does the post.** Choose a folder synced on every computer (Dropbox, Google Drive, OneDrive…) in the host's window (Game by files). From then on:
- the host's game drops each player's turn file there, picks up the orders every 10 seconds, and can generate the year as soon as all the orders are in (a box to tick);
- a player opens **Join a game (shared folder)…** on the welcome screen, chooses the same folder and their empire: their turn opens; **Send my orders** drops them in the folder, and the next turn opens by itself when the host has generated it;
- the host can still play their own empire in the same browser (« Play here »): sending the orders takes them back to the hosted game, which picks them up;
- the files of past years are removed from the folder.

It needs Chrome or Edge on a computer (the other browsers cannot write into a folder). The files contain the whole game: play with people you trust.

**Without a shared folder, the mail is prepared.** The host notes each player's e-mail address; the « E-mail » button saves the turn file and opens your mail program with the address, the subject (game, year, empire) and the message already written. The file still has to be attached by hand: no browser lets an e-mail link attach a file. A player sends their orders back the same way, to the host's address given in the turn file.
