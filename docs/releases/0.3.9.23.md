## What's new in 0.3.9.23: multiplayer on the welcome screen

The game has had play by turn files since 0.3.9 (everyone plays at home, like Stars! by e-mail), but the option only showed once an opponent was set to « Human » in the new game window. The welcome screen now has a **Multiplayer by turn files (PBEM)…** button: it opens a new game already set up for it (one human opponent, « by turn files » ticked, the Opponents tab open). Add or remove human opponents there, then start: this browser hosts the game, sends each player their turn file and receives their orders. A player who receives a turn file opens it with **Import game…**.

The « by turn files » box is now also in the Opponents tab, next to the human players.
