**Jouer dans le navigateur :** https://intelligentrebel.github.io/constellations/

Ou téléchargez `index.html` ci-dessous (tout le jeu en un fichier, il se joue hors ligne), ou `Constellations_v0.3.9.25.zip` avec les sources. Une copie hors ligne de la 0.3.9.18 ou plus récente signale qu'une nouvelle version est sortie.

## Nouveautés de la 0.3.9.25 : une partie par fichiers sans fichiers à envoyer

**Un dossier partagé fait le facteur.** Choisissez, dans la fenêtre de l'hôte (Partie par fichiers), un dossier synchronisé sur chaque ordinateur (Dropbox, Google Drive, OneDrive…). Dès lors :
- le jeu de l'hôte y dépose le fichier de tour de chaque joueur, y relève les ordres toutes les 10 secondes, et peut générer l'année dès que tous les ordres sont arrivés (une case à cocher) ;
- un joueur ouvre **Rejoindre une partie (dossier partagé)…** sur l'écran d'accueil, choisit le même dossier et son empire : son tour s'ouvre ; **Envoyer mes ordres** les dépose dans le dossier, et le tour suivant s'ouvre tout seul quand l'hôte l'a généré ;
- l'hôte peut toujours jouer son propre empire dans le même navigateur (« Jouer ici ») : l'envoi de ses ordres le ramène à la partie hébergée, qui les relève ;
- les fichiers des années passées sont effacés du dossier.

Il faut Chrome ou Edge sur ordinateur (les autres navigateurs ne savent pas écrire dans un dossier). Les fichiers contiennent toute la partie : jouez entre personnes de confiance.

**Sans dossier partagé, le message est préparé.** L'hôte note l'adresse e-mail de chaque joueur ; le bouton « E-mail » enregistre le fichier de tour et ouvre votre logiciel de messagerie avec l'adresse, l'objet (partie, année, empire) et le message déjà écrits. Le fichier reste à joindre à la main : aucun navigateur ne laisse un lien e-mail joindre un fichier. Le joueur renvoie ses ordres de la même façon, à l'adresse de l'hôte donnée dans le fichier de tour.

L'historique complet des versions est dans [README.fr.md](https://github.com/IntelligentRebel/constellations/blob/main/README.fr.md).
