## What's new in 0.3.9.20: a faster interface

Each arrow of the report strip rendered the whole interface again (112 components) and redrew the whole galaxy, twice when the next report took two lines instead of one: the strip grew, the map shrank by 22 pixels, and its canvas was reallocated and redrawn.

- **The report arrows** (and ↑ ↓) now render the strip alone, which is always at least two lines high.
- **The map** is redrawn only when what it shows has changed: hovering or a tooltip no longer redraws it.
- **What the interface computed on every render** (the spec of each colony, the route and spec of each fleet, the simulation of the production queues, the scanners, the refuelling options) is kept while the game does not change: a selection, a dialog or a tab no longer recomputes it, an order does.
- **The engine** simulates a route without recomputing the ships for each simulated year, and finds a ship design without scanning the whole list.

Measured on a 70-year game (48 colonies, 41 fleets): a report arrow costs the browser 8 ms instead of 122 (drawing included). In interface computing time, selecting a planet goes from 44 to 23 ms, a fleet from 70 to 27 ms, the Colonies tab from 100 to 26 ms, and the first selection of a fleet out of fuel (working out which tankers can reach it) from 600 to 250 ms, then instant.
