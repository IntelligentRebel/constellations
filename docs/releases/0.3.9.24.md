Or download `index.html` below (the whole game in one file, it plays offline), or `Constellations_v0.3.9.24.zip` with the sources. An offline copy of 0.3.9.18 or later tells you when a newer version is out.

## What's new in 0.3.9.24

When « Each plays at home, by turn files » is ticked, human opponents now read « Human (at home, by turn files) » instead of « Human (same device) », which made a game by turn files look like a hot-seat game. Nothing else changes: with the box ticked, the game is hosted by turn files, as in 0.3.9.23.

The full history of versions is in [README.fr.md](https://github.com/IntelligentRebel/constellations/blob/main/README.fr.md) (in French).
